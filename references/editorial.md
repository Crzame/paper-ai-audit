# 中文学术文风复核

用途是指出可修改的表达及其替代解释。下列线索没有经过目标域标签验证，不能生成AI率、真实性分数或人机混写份额。

## 保留事实和作者声线

记录原文数字、单位、日期、引文、专有名词、否定、范围和因果限定。分析无需重写；若用户另行要求修改，只修改明确接受的文字，不新增实验、数据、引文或作者经历。学术文章的中性、完整句子、准确术语和必要限定均有功能。

## 检查这些成簇问题

| 线索 | 需要的证据 | 正常替代解释 |
|---|---|---|
| 泛化背景与拔高 | 同段多处可替换主题的意义句，缺少研究对象 | 引言需要说明研究意义；有政策或文献依据时保留 |
| 反复收束 | 对比前后引文，说明重复了什么、是否增加信息 | 摘要和结论重述关键发现有文体功能 |
| 清单与排比 | 指明结构如何妨碍信息，避免只统计三个项目 | 三类真实主体、三阶段生命周期不构成AI证据 |
| 抽象名词与空动词 | 找到缺少主体、动作和证据的具体句子 | 领域概念和指标名称不能按黑名单扣分 |
| 来源含糊 | 哪项主张缺少可核查出处 | 未核实不等于虚构；引用格式问题不证明AI |
| 论证跳跃 | 原文前提和结论分别是什么 | 论文方法问题应单列，不变成作者身份分数 |
| 聊天/草稿残留 | 必须引用精确文本及上下文位置 | 可能在引述AI回答或研究AI；不能只靠字符串定性 |
| 节奏/句长 | 给实际计算单位与分布 | 中文字符长与英文词数不同；变异低不证明AI |
| 异常格式字符 | 给codepoint和位置，保留原件 | Office排版、语言方向、复制粘贴均可能产生 |

“协同、构建、推动、综上、首先、其次”等不是禁词。不要按个人口语习惯要求论文增加第一人称、错别字或不连贯句子。不要把缺少人类故意写错的痕迹当成AI证据。

## 证据记录

每条记录包含：段落/字符位置、短引文、表达问题、学术语境中的替代解释、建议核查的材料。需要主观级别时称“审校优先级”，并明示这是助手判断。不要将整段审校覆盖率称为AI生成率。

## 从开源技能吸收与舍弃的内容

- humanizer / humanizer-zh：吸收事实锁、误判防护与表达复核；不把审校变成来源鉴定。
- de-ai-slop：吸收按语言加载规则、用引文解释；不迁移0–100编辑质量分为AI概率。
- authenticity-check：吸收只读诊断及来源渠道分离；不迁移真实性分数或身份标签。
- ai-check / humanizer-skill：吸收分类证据日志与可复查字符定位；不采用把禁词、完美结构或标点认定为“近乎确定AI”的规则，不继承未经目标域验证的分数阈值。

当开放技能与本任务语境冲突时，只采纳有用途的编辑方法。完整来源、版本和许可证见 sources.json。
