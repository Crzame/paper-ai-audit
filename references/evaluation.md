# 校准与独立评测

目标是尽量少把人工文本误报为AI，同时如实报告因此损失的召回率。目标误报率是待检验目标，不是系统保证。

## 数据与单位

来源标签来自可核查的人写原稿、保存的生成记录或明确的混写区段记录。其他平台的百分比可以衡量平台一致性，不是来源真值。人写并AI润色、完整生成、人工修订生成稿应分开记录，不能强行归入同一来源类别。

分组单位优先为原始文稿/作者/生成提示的家族：翻译、修订、不同窗口和同一提示的人机答案放在同一组。将组分到校准/独立测试；检查重复文本哈希。模型训练集重叠未知则结果仅作研究性对照。

本实现的精确二项上界使用每组每类一个观测；同组同类多条记录或任何重复文本会拒绝计算，避免将相关窗口/重复稿件当成独立样本。若需要每组多段，另用适当的聚类评估，不能伪造不同group_id规避检查。缺省的训练重叠信息按未知处理，只有显式确认无重叠才允许相应验证。

文档级标签评估文档分类。若需要窗口/字符份额，必须有对应区段来源标签及适用的窗口校准；不能把整篇标签下放到每句。

## 输入 JSONL

每行包含：`id`, `group_id`, `split` (`calibration`/`test`), `label` (0人工/1AI), `score` (连续信号), `fingerprint`, `text_sha256`, `language`, `domain`, `unit` 和 `training_overlap_unknown`，另保留来源证据。语言、领域、单位与指纹必须逐行匹配校准声明。`score`若为多模型最小类分数，表示交集信号，不是概率，且所有模型必须对相同范围完整评分。

```powershell
python scripts/calibrate.py --input labelled_scores.jsonl --output profile.json --language zh --domain academic --unit document --target-fpr 0.01
```

只在校准集上选择满足经验FPR约束的最低阈值；在独立测试集上评估一次。不要根据测试结果再调阈值后仍称它为独立验证。

## 样本量与报告

实现采用单侧95% Clopper–Pearson精确二项上界。独立同分布假设下，0误报、n个人工样本的上界为 `1 - 0.05**(1/n)`。0/60仍约4.87%，不足以支持低于1%；0/300约0.994%。这不是跨领域、跨时间或非随机样本的部署保证。

必须同时报告人工/AI样本数、FP、TP、FPR及上界、召回率、精确率、准确率和测试范围。没有被标记样本时精确率为null，不填100%；所有样本均判为人工时的零误报不能被描述成有效检测。

`validated_low_fpr`只在测试上界满足目标且训练重叠已知无问题时启用。它只表示条件性低误报，不表示整体检测有效。调用方还检查校准档版本2、独立样本策略、实际FP和样本数对应的上界、模型版本/温度/分段指纹、语言、领域和分类单位；零AI召回时也不激活检测档。任一不匹配，退回原始信号和不确定结果。

## 本轮公开小样本

HC3-Chinese 的6个问答领域各取12对有效人类/ChatGPT答案，共144条，按问题分组6/6分到校准/测试。排除重复问题/答案及不完整中文路由范围；每个人工测试类只有36条，且不是论文域、训练重叠未知。因此本轮只能检查评测流程和展示误报/召回权衡，不激活论文校准档，也不宣称本技能比原模型更准确。

RAID启发固定FPR下测召回和披露训练重叠；M4/MULTITuDE启发未见领域、语言和生成器测试；DetectRL启发长度、人工修订、混写等压力测试。参考项目的论文指标不能继承为本技能指标。
